## 🆘 Image Troubleshooting Checklist

**Images not showing after upload?**

1. Check GitHub repo has PUBLIC visibility
   - Go to Settings → Visibility → Set to Public

2. Check GitHub Pages is enabled
   - Go to Settings → Pages → Enabled?

3. Verify folder structure in GitHub
   - Click on repo → see `images` folder?
   - Click `images` folder → see 4 files?

4. Clear your browser cache
   - Press Ctrl+Shift+R (Windows/Linux)
   - Press Cmd+Shift+R (Mac)

5. Wait a bit longer
   - GitHub takes 1-2 minutes to process
   - Wait 5 minutes total, then refresh

6. Check file names are EXACT
   - nz-bush.jpg (not nzbush.jpg)
   - ben-image-2.jpg (not ben_image_2.jpg)
   - ben-portrait.png (not benportrait.png)
   - logo.jpg (not LOGO.jpg)
